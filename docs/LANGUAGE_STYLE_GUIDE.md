# Language style guide for questionnaire text

Read this short guide before changing interface text, help, reports, or translations. It is a project writing policy, not a substitute for human language review.

## Addressing the reader

- **Latvian:** address one reader with `Tu`, `Tev`, `Tevi`, `Tavs/Tava` and their case forms, capitalized consistently. The Latvian Language Agency says capitalized `tu/jūs` is customary in letters and notes that use elsewhere depends on the communication context; this project chooses the respectful letter-like form for direct user-facing text.
- **Russian:** address one reader formally with `Вы`, `Вам`, `Вас`, `Ваш` and their forms. The reference rule permits capitals in reusable questionnaires and other texts addressed to one person. Use lowercase when addressing multiple people.
- **English:** use ordinary `you/your` spelling; lowercase except where normal sentence capitalization requires it.

## Tone and editing

- Be calm, welcoming, respectful, and plain. Do not open with “Don’t hurry” or use language that pressures, shames, frightens, or implies a diagnosis.
- Explain choices and privacy directly. Make clear that any question can be skipped and that a professional makes clinical assessments.
- Keep established wording, IDs, codes, conditions, time periods, and source attribution unchanged unless the task explicitly authorizes a question-bank edit.
- Edit interface copy in LV/EN/RU together. EN/RU are drafts and still require human review; automated checks only catch technical consistency.
- Preserve Latvian diacritics and Russian ё where the approved wording uses it. Check punctuation, quotation marks, units, date formats, number spacing, and button labels in the rendered app.

It gives `Вы/Ваш` for polite address to one person, including reusable questionnaire text.
- Gramota.ru, [current explanation of Вы/вы](https://gramota.ru/journal/stati/pravila-i-normy/vy-s-propisnoy-bukvy-pravilo-ustarelo), including lowercase use when addressing several people.
