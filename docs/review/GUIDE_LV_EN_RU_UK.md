# Latviešu

Lejupielādējiet anketas HTML failu un atveriet to pārlūkprogrammā. Priekšskatījumā anketa nedarbojas.

Anketa darbojas bez interneta un nesūta Jūsu datus.

Tehniskās pārbaudes versija; nav klīniski validēts diagnostikas tests.

[Pirmkods: github.com/janisp123/mental-health-questionnaire](https://github.com/janisp123/mental-health-questionnaire)

# English

Download the questionnaire HTML file and open it in your browser. The questionnaire does not work in preview mode.

The questionnaire works offline and does not send your data anywhere.

Technical-review version; not a clinically validated diagnostic test.

[Source: github.com/janisp123/mental-health-questionnaire](https://github.com/janisp123/mental-health-questionnaire)
