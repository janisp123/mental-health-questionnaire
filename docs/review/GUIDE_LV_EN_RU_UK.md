# Latviešu

Atveriet anketu tiešsaistē, vietnē izvēloties “Atvērt anketu”, vai lejupielādējiet HTML failu un atveriet to pārlūkprogrammā lietošanai bez interneta. Faila priekšskatījumā anketa nedarbojas. Pirms aiziešanas vai lietošanas veida maiņas saglabājiet progresu failā; atbildes netiek pārsūtītas automātiski.

Lietotne neapkopo un nekur nenosūta Jūsu datus. Tā palīdz sagatavoties vizītei pie ārsta un nav paredzēta medicīniskas diagnozes noteikšanai. Atbildes uz jautājumiem drīkst interpretēt tikai medicīnas speciālists.

# English

Open the questionnaire online using “Open questionnaire” on the website, or download the HTML file and open it in your browser for offline use. The questionnaire does not work in file previews. Save progress to a file before leaving or switching modes; answers do not transfer automatically.

The application does not collect or send your data anywhere. It helps you prepare for a medical visit and is not intended as a medical diagnosis tool. Only a medical professional may interpret the answers to the questions.

# Русский

Откройте анкету онлайн, выбрав на сайте «Открыть анкету», либо скачайте HTML-файл и откройте его в браузере для работы без интернета. В режиме предпросмотра файла анкета не работает. Перед выходом или сменой режима сохраните прогресс в файл; ответы не переносятся автоматически.

Приложение не собирает и никуда не отправляет Ваши данные. Оно помогает подготовиться к визиту к врачу и не предназначено для постановки медицинского диагноза. Интерпретировать ответы на вопросы может только медицинский специалист.

# Українська

Відкрийте анкету онлайн, вибравши на сайті «Відкрити анкету», або завантажте HTML-файл і відкрийте його в браузері для роботи без інтернету. У режимі попереднього перегляду файлу анкета не працює. Перед виходом або зміною режиму збережіть прогрес у файл; відповіді не переносяться автоматично.

Застосунок не збирає й нікуди не надсилає Ваші дані. Він допомагає підготуватися до візиту до лікаря й не призначений для встановлення медичного діагнозу. Інтерпретувати відповіді на запитання може лише медичний фахівець.
