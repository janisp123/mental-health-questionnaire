# Latviešu

Lejupielādējiet anketas HTML failu un atveriet to pārlūkprogrammā. Priekšskatījumā anketa nedarbojas.

Anketa darbojas bez interneta un nesūta Jūsu datus.

# English

Download the questionnaire HTML file and open it in your browser. The questionnaire does not work in preview mode.

The questionnaire works offline and does not send your data anywhere.

# Русский

Скачайте HTML-файл анкеты и откройте его в браузере. В режиме предварительного просмотра анкета не работает.

Анкета работает без интернета и никуда не отправляет Ваши данные.

# Українська

Завантажте HTML-файл анкети й відкрийте його в браузері. У режимі попереднього перегляду анкета не працює.

Анкета працює без інтернету й нікуди не надсилає Ваші дані.
